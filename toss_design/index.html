소스 라이브러리

수집한 소스를 불러오고 있어요.

사용 장면이 약속보다 먼저다

토스 홈은 기능을 나열하지 않는다. 실제 행동, 한 문장의 이점, 짧은 근거, 한 개의 다음 행동을 순서대로 보여준다.

Data visualization

숫자의 크기보다, 다음 판단을 먼저 보여준다

금융 데이터는 비교 기준, 변화 방향, 실제 값을 함께 제공한다. 색만으로 상승과 하락을 구분하지 않는다.

Global reveal

전 세계 어디서든 마침내 토스 하나로.

우리가 만든 변화가 국경을 넘어 모두의 상식이 될 때, 세상은 마침내 토스 하나로 충분해진다.

Shape language

도형은 장식이 아니라 관계를 설명한다

원은 상태, 선은 흐름, 필은 선택, 둥근 사각형은 콘텐츠 경계를 맡는다. 목적 없는 장식 도형은 만들지 않는다.

Interaction and motion

누른 다음에 무슨 일이 생겼는지 바로 보여준다

빠른 피드백은 150ms, 구성요소 전환은 200ms, 큰 설명 전환은 600ms를 쓴다. 움직임을 줄인 환경에서는 최종 상태를 즉시 표시한다.

컴포넌트는 적고, 상태는 분명하게

버튼과 선택지는 단순한 형태를 유지한다. 차이는 색, 문구, 상태에서 만든다.

이 스터디의 토큰과 아이콘은 실제 웹 CSS와 공개 화면에서 관찰한 패턴을 바탕으로 재구성했다. 공식 TDS 또는 브랜드 자산 배포판으로 사용하지 않는다.

Source coverage

화면에서 보이지 않던 구현 소스까지 확인했다

라이브 페이지의 DOM, 네트워크, CSS와 JavaScript를 다시 대조했다. 이 표는 관찰한 원본과 현재 스터디의 구현 범위를 구분한다.
