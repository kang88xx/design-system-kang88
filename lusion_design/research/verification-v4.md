## 검수에서 수정한 문제

1. 소스 목록 재렌더링 후 키보드 포커스가 사라지던 문제와 과도한 Tab 정지점을 수정했다.
2. spring 적분을 안정적인 해석식으로 바꾸고 큰 주파수·시간 간격을 검사했다.
3. 중첩 `.ds-root`의 이벤트 중복 처리, 다른 인스턴스 다이얼로그 닫힘, 초기화 실패 후 재시도 문제를 수정했다.
4. 비활성 탭 선택, 다이얼로그 반복 열기 시 복귀 포커스 손실, 실행 중 동작 줄이기 대응을 수정했다.
5. 다크 테마 위험 버튼의 전경색과 44px 작은 버튼, 중첩 명시 테마와 실제 복사 CSS의 우선순위를 보완했다.
6. 모바일 미디어 쿼리가 자동 그리드를 덮어써 버튼 문구가 세로로 잘리던 문제를 수정하고 실제 버튼 너비 회귀 검사를 추가했다.
7. 독립 예제의 문서 링크, 예산 오류 연결·해제, 애니메이션 종료, 서버 저장으로 오해할 수 있는 데모 문구를 수정했다.

## 적용 범위

CSS/JS는 프레임워크 독립형이다. 기본 컴포넌트를 기존 프레임워크의 mount/unmount 수명에 연결하며 폼 전송·데이터 저장·권한·비즈니스 로직은 실제 프로젝트에서 연결한다. CSS는 `.ds-root` 범위이며 Shadow DOM 격리가 아니므로 호스트 스타일 영향은 프로젝트에서도 확인한다.

Chromium에서 검증했다. Safari·Firefox·모바일 실기기와 보조공학 전체를 인증한 것은 아니다. 일반 글자 대비의 자동 검사는 특정 기본 토큰 쌍에 대한 검사이며 접근성 전체 인증을 뜻하지 않는다.

공개 원본 22페이지·394에셋, 원본 파생 파일, 재구성의 구분을 유지한다. [소스 감사](source-audit-v3.md)는 기존 수집 파일과 공개 참조 범위에 대한 감사다. 비공개 저장소·DCC 씬은 확보되지 않았으며 대체 구현을 원본으로 표시하지 않았다. 독립 키트에는 수집 원본 미디어·웹폰트를 넣지 않았다.
