검증일: 2026-09-06 KST. 공개 원본 아카이브를 보존하고 독립 구현을 통합했다.

## 기능 검증

- [기존 카탈로그 검사](catalog-checks.json): 16개 통과.
- [확장 페이지 통합 검사](expansion-checks.json): 30개 통과. SVG 검색, 메뉴 Escape와 포커스 복귀, 폼 검증, 테마, 팀, 캐러셀, 카드, 실제 영상 시간 탐색, 3개 시퀀스 포함.
- [모션 검사](motion-checks-v2.json): 25개 통과. WebGL 렌더러, 2,400개 점, 일시정지 픽셀 안정성, 깊이 텍스처, 입자, 포털, 비율 합계, 모션 감소, 390px 및 WebGL 미지원 대체 화면 포함.
- [패키지 검사](package-checks.json): 원본 파일 크기·SHA-256, JSON, 로컬 문서 링크, SVG XML, 영상 프레임 시간 및 경로.

총 71개 브라우저 검사를 통과했다. Chromium 데스크톱·390px 모바일 에뮬레이션 기준이며 실제 iOS/Android 기기 및 모든 GPU 검증은 아니다.

## 수집과 관찰 근거

공개 페이지 22개와 에셋 394개를 검증했다. 인라인 SVG 597회 사용은 [아이콘 manifest](icon-manifest.json)에 페이지·선택자·원문·해시로 연결된다. [영상 프레임 기록](video-frames.json)의 28개 MP4에서 각 5%, 40%, 80% 지점 84장을 추출했다. Blob URL을 사용하고 디코딩된 재생 시각을 확인하여 HTTP Range 미지원 서버의 잘못된 seek를 방지했다. 3장 표본은 모든 프레임의 분석을 뜻하지 않는다.

[원본 추가 캡처](section-captures-v2.json)는 공개 querySettings의 JUMP_SECTION/JUMP_OFFSET, SKIP_ANIMATION, DPR 조절로 가상 스크롤 섹션에 접근했다. 이 정지 화면은 자연 재생 타이밍의 증거가 아니다. 일부 target이 빈 footer 캡처와 hero에 머문 team 시도는 해당 섹션 관찰 근거에서 제외했다. 추가 네트워크 참조를 기존 아카이브와 대조하여 새로 누락된 에셋이 없음을 확인했다.

## 시각 검수

[최종 화면 목록](visual-captures-v2.json)에 데스크톱·모바일 캡처를 기록했다. 직접 검수에서 로고의 흰색 경로가 흰 바탕에 묻히는 문제를 발견해 캐러셀 표시 색상을 검정으로 보정했다. 정사각형 SVG 내부 여백 때문에 로고가 지나치게 작아지는 문제도 표시 크기·크롭으로 보정하고 재캡처했다. 원본 SVG 파일은 보존했다. 제목·컨트롤·카드·깊이 이미지·터널·모바일 폭을 확인했다.

설치 경로에서 visual-verdict 스킬을 찾을 수 없어 스킬 실행을 주장하지 않고 직접 스크린샷 검수와 기능 검사로 대체했다. 기록은 `.omx/state/lusion-system-v2/ralph-progress.json`이며 Ralph 런타임 활성화를 뜻하지 않는다.

## 구현 경계

[재구성 명세](../media/reconstruction-spec.md)에서 원본 근거·독립 구현·생략 요소를 장면별로 구분한다. 원본 physics, FBO fluid, 얼굴/우주비행사 rig, 유리 굴절 렌더의 동일성을 검증하지 않았다. 비공개 원본 파일이나 실제 AI 프롬프트를 확보했다고 표시하지 않는다. 제공한 제작 프롬프트는 유사 결과를 만들기 위한 신규 제안이다.
