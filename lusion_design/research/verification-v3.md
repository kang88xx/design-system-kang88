# v3 검증 기록

검증일: 2026-09-06 KST. 공개 원본 수집과 분석용 추출, 독립 재구성을 구분한다.

## 수집·추출

- 공개 페이지 22개와 에셋 394개를 보존했다. 파일 416개의 크기와 SHA-256을 원장과 대조했다.
- 공개 JavaScript를 AST로 파싱해 클래스 235개와 함수 776개를 분석용 발췌본으로 분리했다. 1,011개 원본 범위와 발췌 결과의 SHA-256을 확인했다. 중첩 함수·클래스는 상위 코드와 겹치므로 추가 수집량이 아니다.
- `.buf` 55개는 메시 34개, 애니메이션 좌표 10개, 점 데이터 11개로 구분된다. 원본 버퍼와 디코딩된 위치·인덱스의 관계는 [BUF 분석](buf-analysis-v3.json)에 기록한다.
- 셰이더 분리 결과와 위치는 [셰이더 기록](source-fragments-v3.json), 최신 공개 참조와 수집 상태는 [수집 감사](source-audit-v3.md)에 있다.

## 기능·화면

- 기존 카탈로그 16개, 확장 기능 30개, 모션 기능 25개 검사를 재실행해 통과했다.
- 소스 탐색기 회귀 검사 15개, 재구성·실제 모델 검사 80개, 실제 소스 통합 검사 20개를 통과했다. [재구성 검사](reconstruction-checks-v3.json)와 [실제 소스 검사](source-live-checks-v3.json)에 결과를 남겼다.
- 전체 6화면의 320·390·812·1000·1440px 가로 넘침, 이미지 로드, JavaScript 오류, HTTP 실패를 검사한 44개 항목이 통과했다. 결과는 [브라우저 통합 검사](workspace-browser-v3.json)에 있다.
- JavaScript 27개와 Python 9개의 구문 검사를 통과했다. 별도 앱 빌드나 타입스크립트 단계가 없는 정적 HTML/CSS/JS 패키지다.
- 루트 HTML과 CSS, 로컬 문서 링크·앵커는 [정적 링크 검사](workspace-checks-v3.json)에 기록한다.

## 검수 중 수정

- 아이콘 라이브러리 문서의 잘못된 `#icons` 링크를 실제 `#symbols`로 수정했다.
- 원본 `captured` 상태가 소스 탐색에서 미확인으로 표시되던 분류를 수정하고 원본·파생·재구성·분석을 구분했다.
- 큰 JavaScript 파일의 미리보기 거절을 부분 읽기로 바꾸고, 이전 요청이 새로 선택한 코드 화면을 덮어쓰지 않게 했다.
- 메인 진입점과 공통 탐색을 보완하고, 파일 목록에서 소스 미리보기로 연결했다.
- BUF 링크의 쿼리/앵커 순서를 바로잡고 선택한 원본에 대응하는 추출 모델로 이동하도록 수정했다. 모델의 느린 응답·로드 실패·다시 선택 후 회복을 검사했다.
- 직접 검수 화면: [실제 추출 인물 모델](../screenshots/decoded-person-v3.png), [실제 ScreenPaint 클래스](../screenshots/source-class-v3.png).

## 범위와 한계

XML 경로가 HTML을 반환하는 사이트맵 1건은 수집 성공에서 제외한다. 공개 참조 및 관측 범위의 누락 검사이며, 비공개 저장소·제작 씬·숨은 경로·모든 외부 프로젝트 사이트의 완전성을 증명하지 않는다. 원본 DCC 씬 대신 공개 배포 좌표를 추출했으며, 절차형 재구성은 원본 엔진·물리·재질·리그와 동일하지 않다.

브라우저 검증은 Chromium과 소프트웨어 WebGL 환경이다. 실제 iOS/Android 및 모든 GPU를 검증한 것은 아니다. 설치된 `visual-verdict` 스킬은 없어 직접 스크린샷 검수와 기능 검사로 대체했다.

현재 전체 패키지는 [v4 ZIP](../downloads/lusion-source-system-v4.zip), 파일 수·SHA-256·CRC 검증은 [패키지 정보](../downloads/package-info.json)에서 확인한다.
