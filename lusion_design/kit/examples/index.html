독립적으로 가져다 쓸 수 있나요?
네. 토큰, 컴포넌트 CSS, 런타임 JS는 외부 폰트, 원본 미디어, 네트워크 요청 없이 동작합니다.
기존 프로젝트 스타일과 충돌하지 않나요?
스타일은 `.ds-root` 범위에서만 적용됩니다. 필요한 경우 `.ds-root`에 커스텀 속성을 덮어쓰면 브랜드 색과 간격을 바꿀 수 있습니다.
접근성 상태는 어디까지 포함되나요?
키보드 탭, ARIA 탭 패턴, 네이티브 폼 검증, 다이얼로그, 토스트 상태, 모션 감소 설정을 기본으로 포함합니다.
