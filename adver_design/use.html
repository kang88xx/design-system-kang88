PROJECT BEHAVIOR

실제 요청은 내 코드에 연결합니다.

프로젝트용 폼은 전송 함수가 없으면 성공을 표시하지 않습니다. onSubmit과 onAction으로 요청 함수를 전달하면, 대기·성공·오류·중복 방지와 해제 시 취소를 런타임이 처리합니다.

const cleanup = ReferenceInteractions.mount(root, {
  async onSubmit({ values, form, signal }) {
    const response = await fetch('/api/inquiries', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(values), signal
    });
    if (!response.ok) throw new Error('Request failed');
    return { message: '요청을 접수했습니다.' };
  }
});

위 경로와 인증·서버 검증은 적용할 프로젝트에서 구현합니다. 스타터는 로컬 콜백으로 연결 흐름을 보여주며 외부로 전송하지 않습니다.
