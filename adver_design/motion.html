마크업을 넣고, 초기화하세요.

  1. 샘플의 코드 보기에서 HTML·CSS·JavaScript를 복사합니다.
  2. 번들의 design-system/ 파일을 프로젝트로 옮깁니다. 프레임워크나 설치 패키지가 필요하지 않습니다.
  3. DOM을 넣은 뒤 mount(container)를 호출합니다. SPA에서 제거할 때 반환된 cleanup을 호출합니다.
<link rel="stylesheet" href="design-system/tokens.css">
<link rel="stylesheet" href="design-system/motion-kit.css">
<!-- 복사한 샘플 HTML -->
<script src="design-system/motion-kit.js"></script>
<script>
  const cleanup = ReferenceMotion.mount(document);
  // 화면을 제거할 때: cleanup();
</script>

인터랙션 예제는 interaction-kit.css / .js와 ReferenceInteractions.mount()를 사용합니다. 독립 HTML 다운로드에는 필요한 코드가 모두 포함됩니다. 폼 예제는 네트워크 전송 없이 상태를 시뮬레이션합니다.
