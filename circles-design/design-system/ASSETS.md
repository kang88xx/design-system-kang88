# 소스와 에셋 구분

이 키트에는 프로젝트용으로 작성한 토큰 매핑, CSS, JavaScript, 타입 선언, 문서·예제만 포함됩니다.

| 항목 | 키트 포함 | 사용 방식 |
| --- | --- | --- |
| 시맨틱 토큰·컴포넌트 코드 | 포함 | 이 프로젝트에서 재구성하고 검증한 구현 |
| Bricolage Grotesque · Be Vietnam Pro · Anonymous Pro | CSS 이름만 포함 | Google Fonts / Fontshare에서 프로젝트가 직접 로드하거나 시스템 폰트로 대체 |
| three circles 로고 마크·아이콘·클라이언트 로고 | 미포함 | 전체 참고 자료 `references/assets/`에 보관된 원본 에셋 |
| 원본 사진·일러스트(hero 원형 사진, 봉투, 프로젝트 이미지) | 미포함 | 전체 참고 자료에서 관찰·비교 |
| Framer 사이트 번들(`framerusercontent.com/sites/...mjs`) | 미포함 | 전체 참고 자료의 소스 근거 |

원본은 Webestica가 제작해 Framer 템플릿 갤러리에 공개한 "three circles" 템플릿입니다. 이 키트는 그 템플릿의 시각 언어를 문서화하고 코드로 재사용하기 위한 것이며, 템플릿 라이선스나 에셋 사용 권한을 이전하지 않습니다. 원본 에셋을 추가할 경우 소비 프로젝트에서 확보한 사용 조건에 따라 관리하세요.

three circles라는 이름은 디자인 참고 대상을 식별합니다. 공식 배포 패키지가 아니며, 폼 전송·예약(cal.com)·뉴스레터 서버와 연결되지 않습니다.
