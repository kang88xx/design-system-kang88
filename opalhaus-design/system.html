Your next site.

01 / INSTALL

Start with the essentials.

정적 HTML은 파일 연결로, 번들러 프로젝트는 로컬 npm 패키지로 시작합니다.

01

HTML / JavaScript

<link rel="stylesheet" href="./design-system/styles.css">
<div class="ods" id="project-ui">
  <button class="ods-button">Let’s talk ↗</button>
</div>
<script type="module">
  import { initOpalhaus } from './design-system/index.js';
  const ui = initOpalhaus(document.querySelector('#project-ui'));
  // ui.refresh(); // 동적 콘텐츠 추가 후
  // ui.destroy(); // 화면 해제 시
</script>

npm / Bundler

npm install ./opalhaus-design-system-1.0.0.tgz

import '@opalhaus-design/system/styles.css';
import { initOpalhaus } from '@opalhaus-design/system';
const ui = initOpalhaus(document.querySelector('.ods'));

npm import 경로와 전체 API는 패키지 README ↗를 참고하세요.

02 / THEMING

A system with room for you.

키트의 토큰 파일을 기준으로 필요한 색상과 폰트만 덮어씁니다. 원본 Framer 전체 CSS를 앱에 전역으로 넣지 마세요.

02
/* styles.css 뒤에 프로젝트 테마를 선언합니다. */
.ods {
  --ods-accent: #ff5d17;
  --ods-font: 'Inter Tight', sans-serif;
  --ods-radius: 12px;
  --ods-section-space: 120px;
}
/* 전체 토큰은 design-system/tokens.css 참고 */

03 / COMPOSE

A small, useful vocabulary.

04 / LIFECYCLE

Connect to your framework.

DOM이 마운트된 뒤 초기화하고 화면이 제거될 때 정리합니다. 새 노드를 추가한 뒤 refresh()로 갱신합니다.

04

React

useEffect(() => {
  const ui = initOpalhaus(ref.current);
  return () => ui.destroy();
}, []);

return <div className="ods" ref={ref}>...</div>;

Vue

let ui;
onMounted(() => {
  ui = initOpalhaus(root.value);
});
onBeforeUnmount(() => ui?.destroy());
// <div class="ods" ref="root">...</div>

프레임워크 제어 상태와 런타임이 같은 속성을 동시에 관리하지 않도록 구성하세요. 실제 의존성·코드 계약은 패키지 README가 기준입니다.
