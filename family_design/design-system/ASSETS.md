# 소스와 에셋 구분

이 키트에는 프로젝트용으로 작성한 토큰 매핑, CSS, JavaScript, 타입 선언, 문서·예제만 포함됩니다.

| 항목 | 키트 포함 | 사용 방식 |
| --- | --- | --- |
| 시맨틱 토큰·컴포넌트 코드 | 포함 | 이 프로젝트에서 재구성하고 검증한 구현 |
| 시스템 폰트 | CSS 이름만 포함 | 기기에서 제공하는 폰트 사용, 폰트 파일 요청 없음 |
| Family 원본 폰트·브랜드 로고·일러스트 | 미포함 | 전체 참고 자료에 보관된 원본 에셋 |
| 원본 앱 MP4·스크린샷·제3자 이미지 | 미포함 | 전체 참고 자료에서 관찰·비교 |
| Family 공개 사이트 JavaScript 번들 | 미포함 | 전체 참고 자료의 소스 근거 |

원본 참고 자료에 대한 별도 사용 권한 문서는 현재 프로젝트에 없습니다. 이 키트의 설치·실행에는 그 자료가 필요하지 않습니다. 원본 에셋을 추가할 경우 소비 프로젝트에서 확보한 사용 조건에 따라 관리하세요.

Family라는 이름은 디자인 참고 대상을 식별합니다. 공식 Family 배포 패키지나 실제 지갑 SDK가 아닙니다. 디자인 시스템에는 계정·거래·시세·인증 API가 없습니다.
