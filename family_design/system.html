COMPOSITION EXAMPLE

프로젝트 기본 정보

카드·폼·버튼·피드백을 조합한 실행 예제입니다. 검증과 제출 상태는 프로젝트가 소유합니다.

이 예제는 입력값을 서버로 전송하거나 저장하지 않습니다.

HTML / JavaScript

<link rel="stylesheet" href="./design-system/styles.css">
<div class="fds" id="project-ui">
  <button class="fds-button">계속하기</button>
</div>
<script type="module">
  import { initFamilySystem }
    from './design-system/index.js';
  const root = document.querySelector('#project-ui');
  const ui = initFamilySystem(root);
</script>

React / Vue 연결

// React: 클라이언트 컴포넌트의 effect
useEffect(() => {
  const ui = initFamilySystem(ref.current);
  return () => ui.destroy();
}, []);

// Vue: 마운트 후 초기화, 해제 시 정리
onMounted(() => {
  ui = initFamilySystem(root.value);
});
onBeforeUnmount(() => ui?.destroy());

상태가 바뀌어 새로운 탭·대화상자를 추가했다면 정리 후 다시 초기화합니다. 제어형 컴포넌트의 상태와 DOM 런타임을 동시에 관리하지 마세요.
